# Contributing to Ninfa Cortes

1. Search [open issues](https://github.com/rodrigobatini/ninfa-cortes/issues) and start with an existing issue when possible. For a new bug or idea, open an issue and describe the use case before you start work.
2. Fork the repository and create a branch for your change.
3. Test the affected flow on Windows when possible. Describe what you tested, your Windows version, and whether you used CPU or CUDA when relevant.
4. Open a pull request to `main` with a link to the issue. Write `Closes #123` on its own line in the description, using the real issue number. The maintainer reviews and merges contributions.

Use English for issues, pull requests, and documentation where you can. Keep changes focused. If you modify the UI, include a screenshot when it helps explain the change. Use examples you can share publicly and remove account data and local paths from logs.

See the [README](README.md#develop) for the Windows build instructions and the [MIT License](LICENSE) for the project's terms.
